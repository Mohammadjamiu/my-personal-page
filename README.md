# my-personal-page

Personal site built with [Astro](https://astro.build).

## Cloudflare Pages

- **Root directory:** `/` (repository root)
- **Build command:** `pnpm install && pnpm run build`
- **Build output directory:** `dist`
- **Environment:** Node 20+ recommended

Connect this repo in the Cloudflare dashboard under **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
