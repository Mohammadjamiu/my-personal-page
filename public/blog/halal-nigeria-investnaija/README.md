# Images for `halal-nigeria-investnaija-stock-guide`

## Copy / rename automatically

From the `mohammads_diary` folder:

```bash
pnpm run copy:halal-images
```

That runs `scripts/copy-halal-notion-images.mjs`, which copies JPGs from  
`ExportBlock-b465a3df-d585-4175-b202-43e9cf6bfdf7-Part-1/`  
into this directory as **`01.jpg` … `25.jpg`** (same order as the Notion “Beginner’s Guide to Halal Investing” screenshots).

Edit the `INVESTNAIJA_MAP` array in that script if your export filenames change.
